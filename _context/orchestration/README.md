## Rules for every agent

1. **Stay in your files.** Your brief names what you own. If you must change a shared file (root `package.json`, `utils/README.md`, `utils/lib/`, `.gitignore`, `nextjs/app/globals.css`), keep the change small and say so in your report.
2. **pnpm only**, never npm or yarn. Node scripts are plain ES modules (`.mjs`).
3. **Media:** never overwrite a source file. Generated media goes in `output/` (gitignored). Test fixtures are generated by the tests themselves (ffmpeg `lavfi` sources), not committed media, unless a fixture is tiny and your brief allows it.
4. **Keys** go in the gitignored root `.env` (template `.env.example`). Never print, commit, or copy a key into a doc.
5. **The dev server:** one is running for this work, the orchestrator's, on http://localhost:3007 from `nextjs/` (started 2026-10-21 at Marlon's request). Check your pages there (`curl -s http://localhost:3007/resources/cli/ffmpeg`, or a browser). Don't start a second one in `nextjs/` (they share `.next/`). If it's down, say so in your report rather than restarting it. (For students the repo's `AGENTS.md` rule stands: they run it themselves.)
6. **Facts:** a tool's flags and behavior come from the installed version (`ffmpeg -h`, `man sox`, `magick -help`), not memory. Put nothing on a page as true unless you checked it.
7. **Git:** agents may share this working tree, so commit by path: `git add <your paths>` then `git commit -m "…" -- <your paths>`; never `git add -A`, `git add .`, or `git commit -a`. Author as Marlon's GitHub account (`mkuzmick`, `29003991+mkuzmick@users.noreply.github.com`). Don't push and don't bump the pointer in The Notebook; the orchestrator does that.
8. **Report in a file:** when you finish or stop, write `_context/orchestration/reports/<the name in your brief>.md` and commit it with your work. Frontmatter: `task`, `thread_id`, `agent`, `started_in`, `resume`, `status`. Sections: **What I built**, **How to try it** (the exact commands), **Commits**, **What I couldn't do or didn't check**, **For other tasks**, **Marlon's words** (quoted exactly), **Decisions and open questions**. Don't edit this board.
9. **Thread ID** in your report: Claude Code `echo $CLAUDE_CODE_SESSION_ID` (resume `claude --resume <id>` from the starting directory); Codex `echo $CODEX_THREAD_ID` (resume `codex resume <id>`). If it's empty, say so.
