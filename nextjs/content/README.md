## This week

This week is about editing: video, audio, and images, in the standard apps and with AI. Editing is the part of making where you decide what stays, what goes, what order the parts go in, and why. You're editing your first project before the October 28 interview, so bring the material you've made.

## Today

We'll tour one app for each medium, then the command line.

- **Audio:** [GarageBand and Logic Pro](/resources/audio).
- **Video:** [iMovie, Final Cut Pro, DaVinci Resolve, and Premiere Pro](/resources/video).
- **Images:** [Photoshop and Lightroom](/resources/images).
- **Command line:** [ffmpeg, ImageMagick, and SoX](/resources/cli), the tools Claude Code can run for you.

## The resource sheets

[Resources](/resources) has one sheet per app and per tool: what it's for, the tour, the basic edit from import to export, the shortcuts to learn first, the AI features built in, and how it works with Claude.
